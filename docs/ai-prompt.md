授業スライドやプリント（PDF・画像・テキスト）を添付して、次のように頼みます。
出力されたら `subjects/<科目>/data.js` に保存し、`npm run check -- <科目>` を通してください。

````text
添付の資料から、学習ドリル用の data.js を作ってください。
書式は下の「ひな形」と同じ API（Drill.setup / mc / tf / inp / fill / calc / ord / match / essay / terms / generators / summary）に厳密に従ってください。

# 方針
- sections は資料の節番号と節タイトル（"7.1": "7.1 ○○"）
- sources は slide（スライド内の例題・確認テスト）/ test（配布されたテスト対策）/ orig（あなたが作る問題）
- 資料にある問題は原文どおりに、それぞれの出典で入れる
- 過去問は source("past") と past("試験名") のあとにまとめて入れ、最後に past(null) で解除する。「「○○」を使って説明せよ」形式は essay にして、指定語をキーワードにする
- orig は各節 20 問程度。形式を混ぜる（選択・○×・穴埋め・計算・並べ替え・対応付け・記述）
- 選択肢は4つ。誤答は同じ節の紛らわしい用語から選ぶ。mc の正解番号は 0 始まり
- 穴埋めはスライドの赤字・太字の語を［A］［B］…にする。表記ゆれしそうなら別解を配列で付ける
- terms はスライドの赤字の語をすべて入れる。説明に用語そのもの（略語の展開も含む）を書かない
- 計算がある科目は generators で数値を毎回変える問題を作る（Drill.util の rnd/pick/fmt を使う）
- summary は節ごとに HTML。覚える語を [[ ]] で囲む。補足は <p class="note">、公式は <div class="formula">、手順は <ol class="flow">
- 解説（最後の引数）は「なぜそうなるか」を1〜2文で。計算は途中式
- 表を読ませる問題は、問題文の中で「|」で始まる行に表を書く（1行目が見出し、「|#R」で表の名前）。コードは `…` で囲む
- 資料の誤植に気づいたら解説に「※スライドには…とあるが…」と書く
- UI 用の説明文（「赤字を隠す」「タップして」など）は問題文に書かない

# ひな形
（subjects/_template/data.js の内容を貼る）
````

## 仕上げのチェック

1. `npm run check -- <科目>` の ERROR をなくす（warn も目を通す）
2. `subjects/<科目>/index.html` をブラウザで開き、各形式を1問ずつ解いてみる
3. まとめを赤シート ON で読み、隠れすぎ・隠れなさすぎがないか確認する
4. `npm run build -- <科目>` で `dist/<科目>.html` を作る
